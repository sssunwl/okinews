旅行小抄

真正有用的旅遊資訊，通常不是景點清單，而是到了現場才會想起的那些小事。

🆘 緊急聯絡

110警察（事故、失竊、糾紛）
119火災・救護車（消防）
050-3816-2787Japan Visitor Hotline・24 小時多語旅客諮詢

號碼以 JNTO 官方頁面 ↗ 為準。手機在日本撥打不需加國碼；租車發生事故一定要先報警取得事故證明，保險才理賠。

🗣️ 旅遊日語（點一下聽發音）

用瀏覽器內建語音朗讀，不需安裝任何 App。iOS 請先關閉靜音鍵。

🚗 機場・自駕重點

  • 靠左行駛，方向盤在右。剛上路先在停車場繞兩圈熟悉車寬再出發。
  • 酒駕零容忍：喝酒後開車、同車乘客與供酒的人都可能被追究。
  • 租車保險：CDW 免責補償之外還有 NOC（營業損失賠償），兩者是分開的，租車時看清楚買了哪一種。
  • ETC 卡要在租車時一起借，否則高速公路只能走現金車道。
  • 導航用電話號碼或 MAPCODE比打地址快，日本地址不是路名制。
  • 那霸機場還車：租車公司多半在機場外，還車後要搭接駁車，班機前預留 90 分鐘比較保險。
