在沖繩下水前，先知道這幾件事

沖繩的海很漂亮，也很真實。浮潛前該確認的安全基本盤。

更新 2026-07-26浮潛海灘沖繩本島

沖繩的海是真的漂亮。但它也是真的海——有流、有生物、有天氣。下水前把這幾件事確認過，剩下的就可以放心玩。

一、優先選有管理的海灘

有救生員、防護網、遊泳期間標示的海灘，安全等級跟自己找的無人海岸完全不同。第一次來、帶小孩、或不熟水性的人，直接選這種。

遊泳期間之外（通常是冬季）多數海灘沒有救生員值勤，這時候的「開放」只代表沒有禁止，不代表有人在看著你。

二、離岸流

離岸流是把人往外海帶的水流，看起來反而是浪比較平的那一條帶狀水面。

被帶走的時候不要正面往岸邊游——那是跟流硬拚，體力會先耗光。正確做法是平行海岸游動，脫離流的寬度之後再往岸邊靠。

三、水母

夏季（大約五月到十月）是水母比較多的季節，其中箱型水母（ハブクラゲ）的螫傷需要立刻就醫。

防護網的作用就是擋這個。另外，長袖防寒衣或水母衣不是為了保暖，是為了防螫——沖繩夏天下水穿長袖是常識，不是怕冷。

四、腳一定要保護

沖繩的海底多是珊瑚礁與礁石，還有海膽。赤腳下水很容易受傷，而珊瑚割傷在熱帶海域很容易感染。準備一雙可以濕的水陸鞋。

順帶一提：踩踏珊瑚會讓它死掉，這件事在沖繩是認真看待的。

五、基本規矩

  • 不要單獨下水。
  • 喝酒後不下水。
  • 身體不適、睡眠不足就不要下水。
  • 防曬乳選對珊瑚友善的配方。

六、聽業者的

如果當地潛水店或海灘管理方說「今天不行」，那就是不行。他們每天看這片海，判斷比任何天氣 App 準。
